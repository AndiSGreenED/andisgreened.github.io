Relevante Windmodelle

Alle Modelle werden weiterhin abgerufen und in den Details angezeigt. Aktiviere/deaktiviere sie direkt im Modellvergleich der Spotkarte: Nur aktive Modelle beeinflussen die Kartenwerte und das Ranking. Die Auswahl bleibt auf diesem Gerät gespeichert.

Es werden nur Spots mit mindestens einer passenden Stunde angezeigt. Ranking-Score = Summe stündlicher Beiträge aus Windfaktor × Wellenfaktor × Richtungsfaktor. Die Hauptwindrichtung erhält ×2 nur bei mindestens 3 zusammenhängenden Stunden im selben Modell.

Datenquellen (kostenlos, ohne Key): Open-Meteo (ICON, GFS, ECMWF an den Spotkoordinaten; zusätzlich ICON-D2, DMI-Harmonie und ICON See auf der nächsten Meereszelle, soweit verfügbar) sowie DWD-Stationsprognose über Bright Sky (nur Deutschland). Zusatzquellen gelten teils nur für heute bis ca. +2 Tage (DWD: gewählter Tag). Google Weather API (optional, mit eigenem Schlüssel) liefert stündliche Windwerte; der Schlüssel wird lokal im Browser gespeichert. Modelle können im Dev-Modus einzeln aktiviert werden.
