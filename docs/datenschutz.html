Datenschutz

Kurz: ANDIsGREENed hat keine Konten, keine Werbung und keine personalisierten Nutzerprofile. Für Seitenaufrufe wird eine cookiefreie, aggregierte Zählung verwendet. APK-Downloads werden über die öffentliche GitHub-Release-Statistik gezählt.

Was auf deinem Gerät bleibt

  • Einstellungen, Standort, eigene Spots, Webcam-Links, Wellensterne, Modellwahl und ein optional eingetragener Google-Schlüssel werden nur auf deinem Gerät gespeichert (Browser- bzw. App-Speicher).
  • Ein optionaler GitHub-Schlüssel zum Veröffentlichen von Spotänderungen wird nach erfolgreicher Verwendung für maximal eine Stunde im Browser- bzw. App-Speicher auf diesem Gerät aufbewahrt. Danach wird er automatisch gelöscht; während dieser Zeit ist eine erneute Eingabe nicht nötig.
  • Dein Standort (GPS oder Ortssuche) wird nur auf dem Gerät verwendet, um Entfernungen zu den Spots zu berechnen. Er wird nicht übertragen.

Welche Dienste die App direkt abfragt

Für die Vorhersage ruft die App öffentliche Wetterdienste direkt von deinem Gerät aus ab. Dabei sehen diese Dienste – wie bei jedem Webseitenaufruf – deine IP-Adresse und die abgefragten Koordinaten der Spots (nicht deinen Standort):

  • Open-Meteo (Wind, Wellen, Modellläufe, Ortssuche)
  • Bright Sky (Daten des Deutschen Wetterdienstes)
  • OpenStreetMap Nominatim (nur bei der Adresssuche für eigene Spots: dein Suchbegriff)
  • Google Weather API (nur, wenn du selbst einen eigenen Schlüssel einträgst)

Die Web-App wird über GitHub Pages ausgeliefert; GitHub protokolliert dabei technisch übliche Zugriffsdaten (z. B. IP-Adresse). Links zu Windfinder, Windy, Webcams usw. öffnen die jeweilige fremde Seite mit deren eigenen Datenschutzregeln.

Für aggregierte Seitenaufrufe verwendet die Web-App GoatCounter. Dabei werden keine Cookies gesetzt und keine Nutzerprofile angelegt. Die Website sieht beispielsweise die besuchte Seite, Browserdaten und technisch eine IP-Adresse. Bei aktiviertem Do Not Track wird standardmäßig nicht gezählt. Über „Wieder einschließen“ kannst du die Zählung auf diesem Gerät ausdrücklich auch bei aktiviertem Do Not Track erlauben. Ein lokaler Opt-out hat immer Vorrang.

Wenn du Spotänderungen veröffentlichst, überträgt dein Browser die geänderten Spotdaten (Richtungen, Position, Wellenstern, Modellwahl und Wellenquelle) zusammen mit deinem GitHub-Schlüssel direkt an die GitHub-API. GitHub speichert diese Änderungen öffentlich im Repository ANDIsGREENed/andisgreened.github.io. Ohne einen GitHub-Schlüssel findet diese Übertragung nicht statt.

Berechtigungen der Android-App

  • Internet – für die Wetterdaten.
  • Standort – nur wenn du „Meinen Standort verwenden“ antippst.

Privacy (English)

No accounts, no ads and no personal profiles. Aggregate, cookie-free page views are counted for app usage. APK downloads are counted through the public GitHub release statistics. All settings, saved spots and your location stay on your device; your location is only used locally to compute distances. The optional GitHub token for publishing spot changes is retained on this device for at most one hour after successful use and then deleted automatically. Publishing sends the edited spot data and token directly to GitHub's API and stores the changes publicly in this repository. The app fetches forecasts directly from Open-Meteo, Bright Sky (DWD), OpenStreetMap Nominatim (address search only) and, if you add your own key, the Google Weather API. These services see your IP address and the coordinates of the spots, not your location. The web app uses GoatCounter for aggregate page views and is hosted on GitHub Pages. Android permissions: Internet (forecasts) and Location (only when you tap “use my location”).
